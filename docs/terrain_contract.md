# 地形排水空间底图数据契约（terrain-v1）

独立的地形与降雨离线数据产品：把数字高程栅格转为可逐格复算的**填洼、平台导流、
汇水分区与径流**数据。仅用 Python 标准库，复用 `common` 的受限 JSON（≤8MB、
拒绝重复键/非有限数/额外字段）与原子报告发布（`common.save`）。不读取网络调度、
计费、水质仓或许可采集状态，不连接外部服务，也不新增任何持久账本；原 `cli`、
`network_cli`、`billing_cli`、`quality_cli`、`permit_collect` 命令行为不变。

```sh
python -m water_rights.terrain_cli --source INPUT --output REPORT
```

业务、校验、计算或 I/O 失败一律退出 2，原因写 stderr，并保留旧报告字节；成功退出 0，
stdout 打印与报告文件相同的 JSON。输入与输出不得同路径（含解析后写回同路径），
输出为符号链接时拒绝；报告经临时文件原子替换发布。

## 输入契约

受限 JSON 文档，顶层字段**准确为** `elevation_mm`、`rainfall_mm`、`cell_area_m2`、
`outlets`，缺一不可、多一不可。

- `elevation_mm`：矩形二维数组，行数与列数均在 1..300；元素为 -10⁶..10⁶ 的整数或
  `null`。`null` 是不可通行掩膜。拒绝布尔（`true` 是 `int` 子类，用 `type(x) is int`
  排除）、浮点与参差矩形。
- `rainfall_mm`：与高程同形同尺寸。有效格为 0..10⁹ 整数；掩膜格必须为 `null`；
  有效格缺测（`null`）直接拒绝，**禁止把缺测当零**。
- 至少一个有效格。`cell_area_m2` 为 1..10⁶ 整数，所有格等面积。
- `outlets` 为非空数组，每项准确为 `{id,row,col}`；`id` 沿用 `common.ident`
  （非空、去空白、≤128 字符、无控制字符）且全表唯一；坐标为从 0 开始的有效格坐标、
  不得落在掩膜上、坐标对不得重复。允许内部出口与同一连通块多个出口；数组次序
  不承载业务优先级。

## 连通性与填洼高程 H（全局最小填洼）

只有共享边的有效格相邻；`null` 格与栅格边界均不可通行。出口是唯一排水终点，
每个有效连通块必须至少包含一个出口，否则报错退出 2（不偷偷补出口、不输出部分分区）。

每格填洼高程定义为：

> **H(c) = 从 c 到任一显式出口的全部有效路径中，路径原始高程最大值的最小值。**

H 同时包含起点与终点高程；出口自身 H 等于其原始高程；原始高程永不被降低，
掩膜边缘不当作出口。填洼只表示排水所需的最小地形抬升，不模拟蓄满过程，不引入
蒸发、渗透或水力坡度。

**依据（不是只报算法名）。** 把每条边的松弛代价写成
`relax(v) = max(H(u), elevation(v))`，该代价沿任何松弛方向单调不减。以全部出口为
初始源（初始值为各自原始高程）做一次 Dijkstra 式堆松弛：堆顶弹出的格其值已不可能
再被任何未弹出路径改善，故弹出值即该格的最小极大路径值；每个有效格只定稿一次，
不可达格在收尾扫描中触发“连通块无出口”错误。这等价于“逐级水位淹没”的定义：
H(c) 是 c 第一次被某个显式出口的 ≤H 淹没区覆盖的最低水位。

## 等 H 平台内的无环导流

在每个 H 相等的连通平台内：

- **锚点（d=0）**：所有出口；以及拥有严格更低 H 邻格的格。
- **d**：该格到最近锚点的平台内最少边数（同 H 边的多源 BFS 距离）。
- 出口无接收格（`receiver = null`）；
- 其他 d=0 格选择 `(H, 行, 列)` 最小的**严格更低 H** 邻格；
- d>0 格选择 `(行, 列)` 最小的、同 H 且距离恰为 d−1 的邻格。

**依据。** 每个等 H 平台必有锚点：否则不存在任何松弛能把该 H 带入平台，而堆仅由
显式出口播种。锚点扫描与逐层 BFS 都按固定行列序，平局只由 `(H,row,col)` 或
`(row,col)` 字典序决定，与遍历先后无关，因此重排 `outlets` 不改变任何格的结果。
每条接收边要么指向严格更低 H，要么指向同 H 的 d−1 格，二元组 `(H,d)` 严格下降，
故接收森林无环；沿接收边必终止于 `receiver=null` 的显式出口。

## 汇流与守恒

标签沿接收边自出口方向前向传播，得到每格最终出口；随后按“接收者在前”的顺序
反向累计：每格计入自身（上游格数含自身）与自身雨量体积，再把累计值并入接收格。

- 体积 = 降雨毫米数 × 格面积，单位**升**（1 mm × 1 m² = 1 L），全程精确整数，
  允许累计值超过输入上限，禁止浮点。
- 每格降雨沿唯一接收链流到出口，**不分叉**；零雨有效格仍计面积与格数。
- 填洼体积 = (H − 原高程) × 格面积（升），按最终出口归属汇总；它**不**增减径流。
- 每个出口的汇流之和等于全域原始降雨体积。

**依据。** 反向累计中每格在自身被加入接收者之前，其全部上游子树已求和完毕；
接收森林把每个有效格恰好挂到一个出口下，故各出口分区两两不交且并集为全部有效格，
出口径流之和恒等于原始降雨总量，面积之和恒等于有效格数 × 格面积。

## 报告契约（terrain-v1）

顶层准确为 `schema_version`、`source_sha256`、`shape`、`cell_area_m2`、`cells`、
`outlets`、`totals`：

- `schema_version`：固定字符串 `"terrain-v1"`。
- `source_sha256`：输入**源字节** SHA256（由 `common.read` 计算）。
- `shape`：`[行数, 列数]`。
- `cells`：与输入同形的矩形二维数组；掩膜位置为 `null`。有效格对象准确为
  `{filled_mm, fill_mm, flat_distance, receiver, outlet_id, upstream_cells, runoff_l}`：
  - `filled_mm`：H；`fill_mm`：H − 原高程（≥0）；`flat_distance`：d；
  - `receiver`：`[row,col]` 或 `null`，仅出口为 `null`；
  - `outlet_id`：最终出口 id；
  - `upstream_cells`：含自身的上游格数；`runoff_l`：含自身的累计降雨升数。
- `outlets`：按 id 的 **Unicode 码点顺序**排列（Python 字符串默认排序），每项准确为
  `{id,row,col,cells,area_m2,runoff_l,fill_l}`，`cells` 为该分区格数。
- `totals`：准确为 `{cells, rainfall_l, fill_l}`，分别是有效格总数、全域原始降雨
  升数、全域填洼升数。

所有数值为精确整数；报告不含时间戳或随机值；同一输入重跑**字节一致**
（`common.save` 固定 `sort_keys`、缩进与换行）；只重排 `outlets` 时，除源字节 SHA
外结果完全相同。

## 复杂度

N = 行数 × 列数（**含掩膜格**）。不含 JSON 读写：

| 阶段 | 时间 | 辅助空间 |
| --- | --- | --- |
| 形状校验与同形图层一次矩形扫描 | O(N) | O(N) 扁平数组 |
| 最小填洼（堆松弛，每格定稿一次） | O(N log N) | O(N) |
| 平台锚点 + 逐层 BFS | O(N) | O(N) |
| 标签传播与反向累计（固定序排序 O(N log N)） | O(N log N) | O(N) |
| **整体** | **O(N log N)** | **O(N)** |

不逐高程单位抬升、不逐水量展开、不为单格枚举路径。全部遍历为显式队列/堆与扁平循环，
无递归调用，长导流链不受 Python 递归深度限制。

## 模块与可调用 API

- `terrain_model.py`：受限输入契约 `parse_input(data) -> 扁平归一化模型`，
  违规抛 `TerrainError`（`ValueError` 子类）。
- `terrain_analysis.py`：`filled_elevations`、`route_plateaus`、`analyze`、
  `build_report`，纯函数、整数精确、无 I/O。
- `terrain_cli.py`：`run(source, output)` 可调用 API 与 `python -m` 命令行。
- `fixtures/terrain_input.json`：自制样例（含掩膜、内部洼地填洼、双出口分区）。
- 测试 `tests/test_terrain.py` + 独立参考 `tests/terrain_reference.py`：阈值连通性
  参考与生产算法互不共享代码，按输出接收边独立复算距离、接收规则、无环、分区与守恒。
